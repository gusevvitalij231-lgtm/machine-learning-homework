# machine-learning-homework

Домашние задания и практические работы по дисциплине "Машинное обучение" за семестр.

## 📋 Содержание репозитория

### Теоретические основы

- **Градиентный_спуск.ipynb** — Введение в градиентный спуск и основные концепции оптимизации моделей
- **Стохастический_град_спуск_практика№1.ipynb** — Практика реализации стохастического градиентного спуска (SGD)
- **Градиент и его друзья.ipynb** — Расширенное изучение производных и градиентов в контексте машинного обучения

### Предварительная обработка данных

- **Отбор_признаков.ipynb** — Комплексное изучение методов отбора признаков:
  - Корреляционный анализ
  - F-test для выбора значимых признаков
  - Значения Шепли (Shapley values) для интерпретации вклада признаков
  - Пермутационная важность (Permutation Importance)

### Методы обучения без учителя

- **Кластеризация.ipynb** — Практика применения алгоритмов кластеризации
  - K-means кластеризация
  - Иерархическая кластеризация
  - Анализ качества кластеризации

- **Детекция_аномалий_SVM/** — Детектирование аномалий с использованием метода опорных векторов:
  - One-Class SVM для обнаружения выбросов
  - Практическая реализация (kt2vovvitsasandann.ipynb)
  - Презентация методологии (anomaly_detection_ocsvm_presentation.pdf)

### Оптимизация моделей

- **Подбор гиперпараметров.ipynb** — Основные техники подбора гиперпараметров
  - Grid Search и Random Search
  - Cross-validation для оценки качества

- **Подбор гиперпараметров_продолжение.ipynb** — Продвинутые методики оптимизации
  - Fine-tuning моделей
  - Анализ влияния различных гиперпараметров

### Контроль знаний и уроки

- **КТ№1.ipynb** — Контрольная работа №1 для проверки понимания основных концепций

- **lesson_3.ipynb** — Третий практический урок (~4.7 MB)
- **lesson_4.ipynb** — Четвертый практический урок (~155 KB)

### Учебные материалы

- **ml_4.pdf** — Лекционный материал №4
- **ml_7.pdf** — Лекционный материал №7

### Наборы данных

- **housing.csv** — Набор данных о жилой недвижимости (~2.1 MB)
- **train_price.csv** — Набор данных для обучения моделей предсказания цен (~460 KB)

## 🎯 Основные темы, изученные за семестр

1. **Оптимизация и градиентные методы** — Понимание того, как машины "обучаются" оптимизируя целевые функции
2. **Подготовка данных** — Выбор наиболее информативных признаков для улучшения производительности моделей
3. **Кластеризация** — Группировка данных без предварительно известных меток
4. **Обнаружение аномалий** — Идентификация выбросов и аномальных примеров в данных
5. **Валидация моделей** — Оценка качества моделей и подбор оптимальных параметров
